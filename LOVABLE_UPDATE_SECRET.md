# ⚡ Pedido para Lovable - Atualizar Secret

## O que fazer:

No **Lovable Helpdesk Interative**, vá em:

**Settings → Secrets**

---

## Encontre:

```
EMAIL_INTAKE_API_KEY
```

---

```

```
