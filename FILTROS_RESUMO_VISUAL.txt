1️⃣  CATEGORIAS (Classificação)
════════════════════════════════════════════════════════════════════════════════

O que faz?
  Classifica automaticamente email em categorias por KEYWORDS

Exemplo:
  Email: "Impressora parou de funcionar"
  Categoria: Impressora
  Keywords: impressora, printer, imprimir, print, papel
  ↓
  MATCH → Classifica como "Impressora"

Padrões Inclusos:
  ✓ Impressora       (printer, imprimir, papel)
  ✓ Rede             (internet, wifi, conexão)
  ✓ Email            (outlook, gmail, enviar)
  ✓ Software         (programa, erro, crash)
  ✓ Hardware         (dispositivo, mouse, monitor)
  ✓ VPN              (remoto, acesso remoto)
  ✓ Banco de Dados   (backup, sql, database)
  ✓ Suporte          (help, problema, ajuda)

Como Adicionar:
  1. Clique "Configurar Categorias"
  2. Clique "Adicionar"
  3. Preencha:
     Nome: [categoria]
     Keywords: [palavra1, palavra2, ...]
  4. Clique "Salvar"
  5. ✓ Pronto! Sincroniza automaticamente

Matching Intelligence:
  ✓ Word boundaries  ("print" não vira "imprimir")
  ✓ Case insensitive ("IMPRESSORA" = "impressora")
  ✓ Multiple keywords (encontra qualquer uma)

2️⃣  WHITELIST (Permitir Automático)
════════════════════════════════════════════════════════════════════════════════

O que faz?
  Define emails/domínios que criam tickets AUTOMATICAMENTE

Exemplo:
  Whitelist: @interative.com.br
  Email: joao@interative.com.br envia qualquer coisa
  ↓
  AUTORIZADO → Cria ticket automaticamente

Tipos:
  ○ Por Email    → suporte@interative.com.br  (apenas esse)
  ○ Por Domínio  → @interative.com.br         (qualquer um do domínio)

Padrão Vazio:
  (você adiciona conforme necessário)

Como Adicionar:
  1. Clique "Configurar Whitelist"
  2. Escolha: Email ○ ou Domínio ○
  3. Digite: suporte@interative.com.br  OU  @interative.com.br
  4. Clique "Adicionar"
  5. ✓ Pronto!

Efeito:
  Email NA whitelist   → Cria ticket ✓
  Email FORA whitelist → Ignorado ou marcado para revisão

3️⃣  PRIORIDADES (Definir Urgência)
════════════════════════════════════════════════════════════════════════════════

O que faz?
  Define prioridade automática baseado em KEYWORDS

Exemplo:
  Email: "URGENTE: Sistema offline"
  Keywords: urgente, offline
  Prioridade: ALTA
  ↓
  MATCH → Marca como ALTA prioridade

Níveis:
  ⭐⭐⭐ ALTA   (urgente, crítico, parado, offline)
  ⭐⭐  MÉDIA   (problema, erro, não funciona)
  ⭐   BAIXA   (dúvida, informação, pergunta)

Padrões Inclusos:
  Alta:
    Keywords: urgente, asap, crítico, parado, offline
    Keywords: problema, erro, não funciona, quebrado

  Baixa:
    Keywords: dúvida, informação, pergunta, como

Como Adicionar Regra:
  1. Clique "Configurar Prioridades"
  2. Clique "Adicionar Regra"
  3. Preencha:
     Keywords: urgente, crítico, asap
     Prioridade: ⭐ ALTA
  4. Clique "Salvar"
  5. ✓ Pronto!

Efeito:
  Email com "urgente" → Prioridade ALTA ⭐⭐⭐
  Email com "dúvida"  → Prioridade BAIXA ⭐
