Visão Geral

O que é o sistema

Plataforma web desenvolvida para empresas que precisam organizar atendimentos, clientes, contratos e equipe em um único lugar, acessível de qualquer dispositivo com internet.

O sistema é entregue instalado, configurado com a identidade da empresa do cliente (nome, logotipo, domínio próprio) e pronto para uso imediato. Não requer instalação local, servidores próprios nem equipe de TI.

Cada cliente recebe uma instalação exclusiva — seus dados são 100% isolados e privados, sem compartilhamento com outros clientes.

Tecnologia

Stack técnica

O sistema é construído com tecnologias modernas, estáveis e de alta demanda no mercado:

React 18 TypeScript Vite TanStack Router Tailwind CSS shadcn/ui Supabase (PostgreSQL) Cloudflare Workers

Frontend

  • React 18 com TypeScript
  • Interface responsiva (desktop e mobile)
  • Tema escuro profissional
  • Roteamento client-side com TanStack Router

Backend e Banco

  • Supabase (PostgreSQL gerenciado)
  • Autenticação com controle de roles
  • Row Level Security — dados por usuário
  • Triggers automáticos (numeração, timestamps)

Infraestrutura

  • Deploy via Lovable (Cloudflare Workers)
  • CDN global — carregamento rápido
  • SSL automático (HTTPS)
  • Sem servidor para o cliente gerenciar

Segurança

  • Autenticação por e-mail + senha
  • Sessão com heartbeat e logout forçado
  • Aprovação de novos usuários pelo admin
  • Log de acessos e ações
Processo

Como é feita a entrega

Após a contratação, o sistema é configurado e entregue em aproximadamente 20 minutos:

1
Coleta de dados Nome da empresa, logotipo, domínio desejado, WhatsApp de contato e módulos contratados.
2
Criação da instância Um repositório exclusivo é criado a partir do template do sistema, com os dados do cliente aplicados automaticamente.
3
Configuração do banco de dados Execução do script de setup que cria todas as tabelas, regras de segurança e dados iniciais no banco dedicado do cliente.
4
Deploy e domínio O sistema é publicado na nuvem e vinculado ao domínio do cliente. Configuração de DNS orientada pelo suporte.
5
Criação do acesso admin Criação do usuário administrador do cliente, com e-mail e senha definidos pelo próprio cliente.
6
Entrega e treinamento Acesso entregue com orientação básica de uso. Suporte nos primeiros dias de operação.
